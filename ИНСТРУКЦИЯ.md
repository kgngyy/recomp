# Как запустить приложение на всех устройствах

## 1. Разместить (5 минут, бесплатно)
Нужен адрес https — без него не работают установка и уведомления.
1. Зарегистрируйтесь на github.com → New repository → название `recomp` → Public → Create.
2. «uploading an existing file» → перетащите ВСЕ файлы из папки (index.html, manifest.json, sw.js, icon-192.png, icon-512.png) → Commit.
3. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты адрес: `https://ВАШ_НИК.github.io/recomp/`
   (Альтернатива: app.netlify.com/drop — перетащить папку, затем создать аккаунт, чтобы сайт не удалился.)

## 2. Установить на устройства
- Телефон Android: Chrome → меню ⋮ → «Установить приложение».
- iPhone/iPad: Safari → «Поделиться» → «На экран Домой» (уведомления — только после этого, iOS 16.4+).
- Компьютер: Chrome/Edge → значок установки в адресной строке.
Откройте раздел «Эта неделя» → «Настройки» → укажите понедельник недели 1 → «Включить уведомления».

## 3. Синхронизация между устройствами (Firebase, бесплатно)
1. console.firebase.google.com → Add project (аналитику отключить).
2. Build → Realtime Database → Create database → регион Europe → «Start in test mode».
3. Вкладка Rules, вставьте и нажмите Publish:
   `{"rules":{"recomp":{"$code":{".read":true,".write":true}}}}`
4. Скопируйте адрес базы вверху вкладки Data (вида https://xxx-default-rtdb.europe-west1.firebasedatabase.app).
5. В приложении: Настройки → «Firebase Database URL» вставьте адрес, код оставьте пустым → «Сохранить».
6. «Ссылка для другого устройства» → откройте её на телефоне/планшете — всё подтянется.
Код синхронизации — как пароль: не показывайте его никому.

## 4. Уведомления, когда приложение закрыто
Обычные веб-уведомления сами по расписанию на закрытом телефоне не приходят. Два надёжных способа:
- Календарь: «Скачать календарь (.ics)» → откройте файл на компьютере/телефоне → добавьте в Google Календарь. Уведомления придут на все устройства. Повторяйте раз в 2 недели.
- ntfy: установите приложение ntfy (iOS/Android) → подпишитесь на тему, например `recomp-ваш-код` → введите тему в настройках → «Запланировать 3 дня». Повторяйте, открывая приложение.
