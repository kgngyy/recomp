# Рекомпозиция тела · годовое руководство

Статический PWA-сайт: 48 недель, 12 макроциклов, чек-лист дня, справочники. Данные хранятся в `localStorage`, по желанию синхронизируются через Firebase Realtime Database.

## Запуск
Страница подгружает разделы через `fetch`, поэтому по `file://` не работает. Нужен любой сервер:

    python3 -m http.server 8000     # затем http://localhost:8000

Для публикации подойдёт GitHub Pages (Settings → Pages → ветка main, корень).

## Структура
    index.html        каркас: меню, экран «Эта неделя», обложка, легенда, шаблоны чек-листов
    css/style.css     все стили (токены, адаптив, печать)
    js/app.js         логика: недели, чек-листы, замеры, синхронизация, ICS, уведомления
    js/lazy.js        ленивая подгрузка content/*.html
    js/ui.js          мобильное меню, переходы по якорям, лайтбокс, service worker
    content/          макроциклы 1–12 и справочники (HTML-фрагменты без внешней <section>)
    img/              схемы макияжа и укладки (WebP)
    icons/, manifest.json, sw.js    PWA

## Синхронизация между устройствами (Firebase)
1. Создайте проект Firebase → Realtime Database (режим тестирования или свои правила).
2. В приложении: «Настройки» → вставьте URL базы (https://…firebaseio.com) и придумайте код.
3. На втором устройстве задайте тот же URL и код.
Не публикуйте ссылку с `?sync=` и не делайте базу открытой на запись для всех: в ней лежат ваши личные отметки.

## Обновление кэша
После изменения файлов увеличьте номер версии `CACHE` в `sw.js`.

## Приватность
В `img/` и в замерах — личные данные. Для публичного репозитория уберите их или сделайте репозиторий приватным.
