# Рекомпозиция v6

## Что где лежит
- **build/** — готовый к деплою сайт. Содержимое заливается в корень репозитория GitHub Pages.
- **split.py** — скрипт миграции (пересобирает `build/` из исходного `index.html`).
- **preview.html** — интерактивный предпросмотр движка (открыть в браузере).
- **index.html** — ваш исходный файл (нужен split.py для пересборки).

## Как развернуть
1. Содержимое `build/` скопируйте в репозиторий `recomp` на GitHub.
2. `Settings → Pages → Source: Deploy from a branch → main → / (root)`.
3. Через 1–2 мин приложение доступно по `https://ВАШ_НИК.github.io/recomp/`.

## Пересборка
